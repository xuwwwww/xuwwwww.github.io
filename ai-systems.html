What It Does 它在做什麼

ArmTune

Checks Arm Linux targets, CPU topology, runtime capability, model paths, and benchmark readiness before tuning starts. 在調校前先檢查 Arm Linux 主機、CPU topology、runtime 能力、模型路徑與 benchmark 準備狀態。

llama.cpp

Builds portable, native, and optimized profiles, then compares throughput and latency under fixed test rules. 建立 portable、native、optimized profile，並在固定測試規則下比較 throughput 與 latency。

Serving Search

Runs staged searches for llama-server settings, concurrency, slots, batch choices, and recommendation classes. 針對 llama-server 設定、concurrency、slots、batch 選項與推薦類型做分階段搜尋。

Guarded Apply

Shows, validates, dry-runs, applies, checks status, and rolls back recommendations instead of blindly changing a machine. 推薦不會直接亂套用；先顯示、驗證、dry-run，再支援套用、狀態檢查與 rollback。

02

Workflow 工作流程

1

Inspect the target 檢查目標主機

Confirm Linux Arm64, CPU model, SSH trust, runtime tools, model file, and benchmark readiness. 確認 Linux Arm64、CPU 型號、SSH 信任、runtime 工具、模型檔案與 benchmark 狀態。 

autotuneai arm doctor --target-config target.json --require-production
2

Build and compare profiles 建立並比較 profile

Build llama.cpp variants and compare them with fixed prompt, thread, model, and repetition settings. 建立 llama.cpp 版本，並用固定 prompt、thread、model 與重複次數比較。 

autotuneai arm build-profile --config build_profiles.json
3

Search runtime settings 搜尋 runtime 設定

Try bounded candidates such as thread count, CPU affinity, batch settings, and serving slots. 在範圍內測 thread 數、CPU affinity、batch 設定與 serving slots。 

autotuneai arm optimize --config llama_bench_optimize.json
4

Create a recommendation 產生推薦

Package the selected settings with workload scope, checks, and the reason it was selected. 把選出的設定、適用 workload、檢查條件與選擇原因包成推薦檔。 

autotuneai serve recommend --workload interactive-short --concurrency 4
5

Run the chosen setup 執行選出的設定

Start the best serving profile through the CLI while keeping the recommendation scoped to the tested environment. 用 CLI 啟動最佳 serving profile，並保留它只適用於測過環境的邊界。 

autotuneai serve run --best --workload interactive-short --concurrency 4
6

Apply and roll back 套用與回復

Validate, canary, lease, status-check, and roll back process-scoped recommendations. 支援 validate、canary、lease、status check，以及 process scope 的 rollback。 

autotuneai recommendation apply --bundle recommendation.json --dry-run
