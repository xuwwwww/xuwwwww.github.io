PerfRunbench

PerfRunbench is my benchmarking and tuning toolkit for real workloads. ArmTune adds an Arm-focused path: inspect the target, build llama.cpp profiles, run bounded runtime searches, measure llama-server serving behavior, produce a Performance Passport, and apply recommendations with validation and rollback. PerfRunbench 是我針對真實工作負載做 benchmark 與調校的工具。ArmTune 是其中的 Arm 路線：檢查目標主機、建立 llama.cpp profile、執行有界 runtime 搜尋、量測 llama-server serving 表現、產生 Performance Passport，並以可驗證與可回復的方式套用推薦。

01

What It Does 它做什麼

Target Inspection

Validates Linux Arm64 readiness, CPU topology, runtime tools, model paths, SSH trust, artifact destinations, and production benchmark requirements before a run starts.在開始調校前檢查 Linux Arm64 readiness、CPU topology、runtime 工具、模型路徑、SSH trust、artifact 輸出位置與 production benchmark 條件。

Build Profiles

Builds portable, arm-native, and optimized llama.cpp variants while preserving CMake cache, compile commands, binary hashes, and build evidence.建立 portable、arm-native 與 optimized llama.cpp variants，並保留 CMake cache、compile commands、binary hash 與 build evidence。

Runtime Search

Runs staged candidate searches over threads, CPU affinity, batch settings, and serving parameters with paired baselines and a configured noise band.針對 threads、CPU affinity、batch 設定與 serving 參數做階段式 candidate search，搭配 paired baseline 與設定好的 noise band。

Guarded Apply

Packages recommendations with tested scope, status checks, dry-run behavior, process-scoped apply, lease tracking, and rollback.把推薦結果包成有測試範圍、狀態檢查、dry-run、process-scoped apply、lease tracking 與 rollback 的 RecommendationBundle。

02

Workflow 流程

1

Inspect and gate檢查與 gate

Run doctor and host inspection before touching a remote machine or claiming benchmark readiness.先跑 doctor 與 host inspection，再碰遠端主機或宣稱 benchmark ready。

autotuneai arm doctor --target-config target.json --require-production
2

Build evidence-backed profiles建立可追溯 profile

Create profile plans, execute fixed builds, and preserve hashes and compiler evidence.建立 profile plan、執行固定 build，並保存 hash 與編譯證據。

autotuneai arm build-profile --config build_profiles.json
3

Compare and search比較與搜尋

Compare build profiles, then run bounded runtime search with a staged candidate set.先比較 build profile，再用階段式 candidate set 做有界 runtime search。

autotuneai arm optimize --config runtime_search.json
4

Measure serving behavior量測 serving 行為

Use llama-server to capture request completion, nonempty output, TTFT, end-to-end latency, cleanup, and port release.用 llama-server 量測 request completion、nonempty output、TTFT、end-to-end latency、cleanup 與 port release。

autotuneai arm optimize --config llama_server_secondary.json
5

Generate a Passport產生 Passport

Turn measured profile comparison into a scoped Performance Passport and verify its required evidence.把實測 profile comparison 轉成有範圍限制的 Performance Passport，並驗證必要證據。

autotuneai arm passport --comparison-result profile_comparison_result.json
6

Apply with rollback套用與回復

Apply only process-scoped recommendations after validation, with status checks and rollback kept in the workflow.只在驗證後套用 process-scoped 推薦，流程中保留 status check 與 rollback。

autotuneai recommendation apply --bundle recommendation.json --dry-run

Recent Measured Results 近期實測結果

llama-bench +61.94%

Build-profile decode median improved from 10.825 to 17.530 tok/s, portable-baseline to arm-native.build-profile decode median 從 10.825 提升到 17.530 tok/s，portable-baseline 對 arm-native。

Runtime Search +28.25%

Bounded runtime search improved decode median from 13.630 to 17.480 tok/s under the tested protocol.有界 runtime search 在測試協定下讓 decode median 從 13.630 提升到 17.480 tok/s。

Serving TTFT +35.40%

llama-server TTFT median dropped from 97.260 ms to 62.826 ms, reported as lower latency.llama-server TTFT median 從 97.260 ms 降到 62.826 ms，以 latency 降低方式呈現。

Serving E2E +37.34%

End-to-end median latency dropped from 2114.831 ms to 1325.070 ms for the same measured profile comparison.同一組 profile comparison 中，end-to-end median latency 從 2114.831 ms 降到 1325.070 ms。

Scope: one user-provisioned C7g / Graviton3 Arm64 target, Qwen2.5-7B Q4_K_M, pinned llama.cpp source, fixed prompt and measurement protocols. These are measured results, not a global optimality or cross-instance portability claim. 範圍：單一 user-provisioned C7g / Graviton3 Arm64 目標、Qwen2.5-7B Q4_K_M、固定 llama.cpp source、固定 prompt 與量測協定。這是實測結果，但不是全域最佳化或跨機型可攜性的宣稱。
