PerfRunbench

PerfRunbench runs training and inference workloads with CPU, memory, and GPU guards; compares reversible runtime and host settings; and records every experiment in HTML and JSON. The same framework supports local, systemd, and Docker executors across Windows/WSL, Linux with NVIDIA GPUs, and Arm systems. ArmTune is its dedicated path for measured Arm inference tuning. PerfRunbench 可在 CPU、記憶體與 GPU 資源限制下執行訓練與推論工作負載，比較可回復的 runtime 與主機設定，並以 HTML 和 JSON 保存每次實驗。相同框架支援 Windows/WSL、Linux + NVIDIA GPU 與 Arm 系統上的 local、systemd、Docker executor；ArmTune 則是其中專門處理 Arm 推論實測與調校的流程。

01

What It Does 它做什麼

Resource-Guarded Runs

Wraps arbitrary training and inference commands with CPU, memory, and GPU budgets, run-state tracking, cleanup, and executor-specific lifecycle checks.以 CPU、記憶體與 GPU budget 包裝任意訓練或推論指令，並處理 run state、cleanup 與不同 executor 的 lifecycle check。

Reversible Tuning

Applies process, runtime, Linux, WSL, Windows, and NVIDIA profiles with pre-run snapshots, post-run checks, restore, and rollback.套用 process、runtime、Linux、WSL、Windows 與 NVIDIA profile，並保留執行前 snapshot、執行後檢查、restore 與 rollback。

Measured Search

Searches candidate settings with fixed workloads, paired baselines, configured noise bands, and statistical confirmation instead of assuming that aggressive settings are faster.使用固定工作負載、paired baseline、noise band 與統計確認搜尋候選設定，而不是假設較激進的設定一定較快。

Reports and Recommendations

Produces traceable HTML/JSON comparisons and packages eligible settings with their measured scope, evidence, dry-run behavior, status checks, and rollback path.產生可追溯的 HTML/JSON 比較，並把合格設定與實測範圍、證據、dry-run、狀態檢查及 rollback 路徑一起保存。

02

Cross-Platform Scope 跨平台範圍

Windows / WSL

Profiles Windows and WSL workloads, records CPU and memory state, and runs fixed-batch GPU experiments with NVIDIA monitoring and rollback.分析 Windows 與 WSL 工作負載，記錄 CPU／記憶體狀態，並以 NVIDIA monitoring 與 rollback 執行固定 batch 的 GPU 實驗。

Linux / NVIDIA

Combines system, runtime, and GPU profiles on Linux while checking whether each profile helps, stays within noise, or causes a regression.在 Linux 上組合 system、runtime 與 GPU profile，並判斷各設定是有效、落在雜訊範圍內，或造成退步。

ArmTune

Inspects Arm64 targets, builds portable and Arm-specific llama.cpp profiles, searches runtime settings, measures llama-server behavior, and creates a Performance Passport.檢查 Arm64 主機、建立 portable 與 Arm 專用 llama.cpp profile、搜尋 runtime 設定、量測 llama-server，並產生 Performance Passport。

Experimental Workloads

Keeps workload adapters separate from the framework, including PyTorch/timm inference, synthetic pressure tests, llama.cpp, and an optional BootTrace structured-output workload.將 workload adapter 與框架分離，涵蓋 PyTorch/timm inference、synthetic pressure test、llama.cpp，以及選用的 BootTrace structured-output workload。

03

ArmTune Workflow ArmTune 流程

1

Inspect and gate檢查與 gate

Run doctor and host inspection before touching a remote machine or claiming benchmark readiness.先跑 doctor 與 host inspection，再碰遠端主機或宣稱 benchmark ready。

autotuneai arm doctor --target-config target.json --require-production
2

Build evidence-backed profiles建立可追溯 profile

Create profile plans, execute fixed builds, and preserve hashes and compiler evidence.建立 profile plan、執行固定 build，並保存 hash 與編譯證據。

autotuneai arm build-profile --config build_profiles.json
3

Compare and search比較與搜尋

Compare build profiles, then run bounded runtime search with a staged candidate set.先比較 build profile，再用階段式 candidate set 做有界 runtime search。

autotuneai arm optimize --config runtime_search.json
4

Measure serving behavior量測 serving 行為

Use llama-server to capture request completion, nonempty output, TTFT, end-to-end latency, cleanup, and port release.用 llama-server 量測 request completion、nonempty output、TTFT、end-to-end latency、cleanup 與 port release。

autotuneai arm optimize --config llama_server_secondary.json
5

Generate a Passport產生 Passport

Turn measured profile comparison into a scoped Performance Passport and verify its required evidence.把實測 profile comparison 轉成有範圍限制的 Performance Passport，並驗證必要證據。

autotuneai arm passport --comparison-result profile_comparison_result.json
6

Apply with rollback套用與回復

Apply only process-scoped recommendations after validation, with status checks and rollback kept in the workflow.只在驗證後套用 process-scoped 推薦，流程中保留 status check 與 rollback。

autotuneai recommendation apply --bundle recommendation.json --dry-run

Recent Measured Results 近期實測結果

Windows · RTX 3060 +9.80%

Paired normalized improvement on a fixed-batch timm inference sweep; raw throughput increased from 215.629 to 224.735 samples/s.固定 batch 的 timm inference paired sweep，normalized improvement 為 9.80%；raw throughput 從 215.629 提升至 224.735 samples/s。

WSL · RTX 3060 +6.69%

Paired normalized improvement on the matching WSL fixed-batch sweep; raw throughput increased from 209.000 to 218.628 samples/s.相同固定 batch protocol 的 WSL paired sweep，normalized improvement 為 6.69%；raw throughput 從 209.000 提升至 218.628 samples/s。

llama-bench +61.94%

Build-profile decode median improved from 10.825 to 17.530 tok/s, portable-baseline to arm-native.build-profile decode median 從 10.825 提升到 17.530 tok/s，portable-baseline 對 arm-native。

Runtime Search +28.25%

Bounded runtime search improved decode median from 13.630 to 17.480 tok/s under the tested protocol.有界 runtime search 在測試協定下讓 decode median 從 13.630 提升到 17.480 tok/s。

Serving TTFT +35.40%

llama-server TTFT median dropped from 97.260 ms to 62.826 ms, reported as lower latency.llama-server TTFT median 從 97.260 ms 降到 62.826 ms，以 latency 降低方式呈現。

Serving E2E +37.34%

End-to-end median latency dropped from 2114.831 ms to 1325.070 ms for the same measured profile comparison.同一組 profile comparison 中，end-to-end median latency 從 2114.831 ms 降到 1325.070 ms。

Each result belongs to its own host and protocol. Windows/WSL figures use fixed-batch timm sweeps on an RTX 3060 Laptop GPU. Arm figures use one C7g / Graviton3 Arm64 target, Qwen2.5-7B Q4_K_M, pinned llama.cpp source, and fixed measurement protocols. They are not a global optimum or a cross-platform speedup claim. 每組結果只適用於各自的主機與 protocol。Windows/WSL 數據來自 RTX 3060 Laptop GPU 的固定 batch timm sweep；Arm 數據來自單一 C7g / Graviton3 Arm64 主機、Qwen2.5-7B Q4_K_M、固定 llama.cpp source 與量測協定。這些結果不代表全域最佳值，也不能合併成跨平台加速宣稱。
